# Castro Decor — Blog de Afiliados

Projeto do blog da Castro Decor para conteúdo SEO e divulgação de produtos para casa.

## Estrutura

- index.html — página principal
- style.css — identidade visual e responsividade
- imagens/ — imagens e identidade visual
- produtos/ — área reservada para dados futuros dos produtos

## Objetivo

Criar páginas de conteúdo sobre decoração, utilidades, eletrônicos, eletrodomésticos, móveis e achadinhos, com links de afiliado.

## Importante

Os marcadores LINK_AFILIADO_XX e IMG_PRODUTO_XX precisam ser substituídos pelos dados reais de cada produto antes da publicação.
